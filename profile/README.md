Decision Clarity is an independent studio building websites and AI tools for small businesses and teams. Everything here is live: you can click through and use it, not just look at it.
What's here
AI automation demos. Working tools that run a live model call and return structured results, lead intake classification and receipt/invoice extraction, each with server-side keys, rate limiting, and honest handling of missing data.
Website templates. Complete, deployable sites for local service businesses and professional firms. Pick a shell, we configure it.
The code. Public and readable, so you can see how it's built.
How it's built
Front end: HTML, CSS, vanilla JS
Back end: Vercel serverless functions (Node)
Data & infra: Redis (rate limiting), PostgreSQL, Git, GitHub Actions
AI: Claude API, structured output, retrieval
The background behind it: years of enterprise IT and infrastructure architecture, brought down to the scale a growing business actually needs.
